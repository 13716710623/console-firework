## 三、性能数据

| 场景 | 目标 | 实测 | 偏差 |
| --- | --- | --- | --- |
| 300 帧 @60 FPS | 5.00 s | 4.94 s | −1.2% |
| 300 帧 @30 FPS | 10.00 s | 9.93 s | −0.7% |
| 3000 帧 @1000 FPS（无休眠压力） | ≈3 s | 3 s | — |
| 单帧输出体积 | 80×24 字符 + 换行 ≈ 1.97 KB | 1.97 KB/帧 | — |
| CPU（60 FPS，无限模式） | 不应占满单核 | 末段自旋约 10% 单核 | 合理 |

> 60 FPS 略高于目标，是「高精度定时器 + 末段自旋」为保证不超时留的余量；30 FPS 下偏差 0.7%，说明帧同步有效。

## 五、边界与异常场景

| 场景 | 处理 |
| --- | --- |
| 控制台尺寸读取失败（重定向/无 TTY） | 回退 80×24（`cols/rows` 先初始化，避免读到栈垃圾） |
| 控制台过小（<10 列或 <5 行） | 回退 80×24 |
| 尺寸异常（>MAX 或 ≤0） | 帧缓冲渲染前防御性返回，不越界 `memcpy` |
| 粒子数达到 4096 上限 | 丢弃新增粒子并累加 `g_drop_count`，不越界写 |
| 火箭飞出顶部才爆炸（y<0） | 爆炸点 y 夹紧到 1，避免粒子出生即销毁 |
| `--fps 0` / 负数 | 回落默认 30 |
| `--frames` 负数 | 视为 0（无限） |
| 运行中改变窗口尺寸 | 每 30 帧重读尺寸，变化时清屏重绘 |

## 六、结论

- 功能覆盖赛题全部必做项（多烟花并行、随机爆炸规模、容错保护）与加分项（任意键退出）。
- 编译零警告，关键指标（帧率、可复现性、长跑稳定性）均有量化实测。
- 已知限制集中在「运行中改变窗口尺寸不重排」与「爆裂呈粒子云而非严格射线」，已在 README 中如实说明。
