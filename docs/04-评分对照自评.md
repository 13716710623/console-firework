## 四、答辩三句话

1. **Agent 配置**：Codex CLI + GLM-4.6（Responses 端点），系统提示词分「角色 / 硬性规范 / 本轮任务」三段，每轮把编译器绝对路径写死，避免「找不到 gcc 就交付未编译代码」。
2. **AI 幻觉**：最能说明问题的是「已经按实际耗时补齐帧率」——算术对、平台行为错，Windows `Sleep` 15.6ms 粒度让 60fps 掉到 40fps；用墙钟时间一测就露馅，换成可等待定时器 + 末段自旋后 4.95s/5.00s。
3. **工程闭环**：每轮 Prompt、原始输出、源码快照、抓帧与测试数据全部留档，12 条自动化用例覆盖编译、帧率、可复现、边界、长跑、尺寸变化，结论都能当场复现。
