# 控制台字符烟花粒子系统

> 2026 年嵌入式技术应用开发校赛 ·「基于 AI Agent 辅助开发的控制台字符烟花粒子系统」

纯 C99、单文件、零第三方依赖。用 `@ O o * , .` 六级字符表现亮度，包含火箭升空、三种爆裂形态、粒子拖尾、重力下坠与终端自适应。

## 特性

- **基础**：随机发射点、上升拖尾、随机高度爆炸、初速度 + 重力 + 生命周期、四边界消失
- **增强**：最多 6 发烟花并行、每发 192~384 粒子随机、粒子池 4096 上限与全量判界
- **形态**：牡丹（实心放射）/ 柳条（下垂光丝）/ 环形（空心环）随机
- **细节**：8 方向粒子拖尾、火箭上升烟迹、爆心闪光、空气阻力、重力曲线、火星二次爆裂、闪烁
- **交互**：任意键退出（Windows `_kbhit` / POSIX `termios` 非阻塞）
- **自适应**：每 30 帧重读终端尺寸，窗口变化后清屏重排
- **可测试**：`--frames/--fps/--seed/--size/--ansi/--selftest/--help`

## 编译运行

```bash
gcc firework.c -o firework -Wall -Wextra
./firework
```

Windows 下产物为 `firework.exe`，双击即可；运行中按任意键退出。

```bash
make          # 编译
make run      # 无限模式
make test     # 内置自检 + 300 帧冒烟
```

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--frames N` | 0（无限） | 跑 N 帧后退出 |
| `--fps F` | 30 | 目标帧率 |
| `--seed S` | 时间 | 固定种子，可逐字节复现 |
| `--size WxH` | 跟随窗口 | 强制画布尺寸（录屏/测试） |
| `--ansi` | 关 | 每帧 ANSI 光标归位，便于抓帧 |
| `--selftest` | — | 内置断言：亮度映射 / 边界 / 粒子池 / 紧凑删除 |
| `--help`, `-h` | — | 用法 |

## 实测

| 项 | 结果 |
| --- | --- |
| 编译 | `-Wall -Wextra` 零警告（GCC 15.3.0） |
| 帧率 | 300 帧 @60fps 实测 4.94s（目标 5.00s） |
| 可复现 | 同 seed 两次输出 SHA-256 一致 |
| 长跑 | 3000 帧 3s，无崩溃、无越界 |
| 自检 | `SELFTEST PASS` |
